An open-source S3 client for Windows, macOS and Linux

Browse buckets, transfer files with pause and resume, sync folders and script it all from the bb command line. One Rust core powers both the desktop app and the CLI.

Download Source on GitHub

Features

Everything you need to work with S3 and S3-compatible storage.

Reliable transfers

Multipart uploads with checksums, pause, resume and retry, a shared bandwidth cap, and resume after a restart. A cancelled transfer never leaves a partial object behind.

Folder sync

Analyse first, then execute. Upload, download or two-way sync with optional deletes and saved filters.

Safe by default

Keys live in the OS keychain with an optional master password. Typed confirmation guards destructive actions, and objects can be encrypted before upload.

Works beyond AWS

Custom endpoints, path-style addressing, requester pays and per-bucket region routing. Menus hide what a server does not support.

Rich object tools

Properties, HTTP headers, user metadata, tags, storage class, versions, previews, share links and listing export.

Scriptable

The bb CLI prints NDJSON with --json, supports --dry-run and uses stable exit codes.

A closer look

Transfers, properties, folder sync and context menus.

Command line

The same core, in your terminal.

bb account add --label work --access-key-id AKIA...
bb ls s3://my-bucket/photos/ --long
bb cp ./site s3://my-bucket/www/ --recursive --exclude '*.tmp'
bb sync ./backup s3://my-bucket/backup --delete --dry-run
bb presign s3://my-bucket/file.zip --expires 1h

Private and open

No telemetry

BucketBridge talks only to the storage endpoints you configure.

Keychain storage

Secrets stay in the OS keychain, optionally sealed with a master password.
