The open-source S3 client for Windows, macOS and Linux

A free S3 file manager for Amazon S3 and S3-compatible storage. Browse buckets, move files through a resumable queue, keep folders in sync and script it all with the bb CLI. One Rust core, no account, no telemetry.

Features

Everything you do with buckets, in one app

For Amazon S3 and S3-compatible storage such as MinIO: custom endpoints, path-style addressing and per-bucket regions.

Reliable transfers

Multipart uploads with checksums, pause, resume and retry, one bandwidth cap, and resume after a restart. An overwrite policy decides what happens when a file already exists.

Drag and drop

Drag objects between folders, buckets, accounts and windows to copy them, hold a key to move, or drop files from Finder or Explorer to upload.

Folder sync

See every change in a dry run first, then sync up, down, both ways or bucket to bucket. Saved jobs, exclusion files and a summary report.

Every way to sign in

Access keys, AWS profiles, IAM Identity Center (SSO), assumed roles with MFA and instance roles. Several accounts at once, grouped in folders.

Safe by default

Secrets stay in the OS keychain, optionally behind a master password. Confirmations guard deletes, and files can be encrypted before they leave your machine.

Preview and edit

Zoom into images, page through CSV and Parquet as tables, read formatted JSON and XML, and edit an object in place: each save is uploaded.

Bucket and object settings

Policies, public access block, versioning, CORS, lifecycle, replication, object lock, tags, headers, encryption, IAM users and CloudFront.

Share and link

Presigned links with a sharing wizard, "Copy as" any URL form, and bb:// links that open the app at a bucket and folder.

Tools

Bucket usage, a security scan, connection diagnostics, unfinished upload cleanup, listing export, and mounting a bucket as a drive.

Full feature list

Everything BucketBridge can do

Every feature below ships in the free download, on Windows, macOS and Linux.

Accounts and security

  • Several accounts at the same time, each with its own region, endpoint and settings
  • Credentials from access keys, AWS profiles (~/.aws/config), IAM Identity Center (SSO), assumed roles or EC2/ECS instance roles
  • Account folders and reordering; export and import of accounts without secrets
  • Secrets in the OS keychain (macOS Keychain, Windows Credential Manager, Secret Service), never in plain text
  • Optional master password (Argon2id and AES-256-GCM)
  • MFA with temporary STS session credentials kept in memory
  • HTTP and SOCKS5 proxies with authentication and a bypass list
  • Custom endpoints, path-style addressing and requester pays for S3-compatible storage

Browsing and objects

  • Bucket tree with a filter by name, region and creation date
  • Folders, flat browsing, search, paging, bookmarks and several windows
  • Editable address bar for pasted s3:// paths, and bb:// links
  • Natural sorting; sort order and column widths are remembered
  • Upload, download, copy, move, rename, delete and create folders
  • Drag and drop between folders, buckets, accounts and windows, and from the file manager
  • Copy and move across accounts, with a server-side copy where possible
  • Edit in place: every save is uploaded, with a check for changes by others
  • Copy as name, key, s3:// URI, virtual-hosted or path-style URL
  • Preview images (zoom and pan, animated GIF), text, JSON, XML, and CSV, TSV and Parquet as tables

Transfers

  • Transfer queue with concurrency, pause, resume, cancel and retry
  • The queue survives an app restart, and transfers resume where they stopped
  • Multipart uploads with automatic part sizes, and server-side copy of objects over 5 GiB
  • One bandwidth cap shared by all transfers
  • Overwrite policy: overwrite, skip, overwrite if newer, rename or ask
  • File modification times are kept
  • Checksums (CRC32 by default, CRC32C, CRC64NVME, SHA-1, SHA-256) and validated downloads
  • Client-side encryption (AES-256-GCM) with optional gzip or zstd compression

Folder sync

  • Upload, download, both ways or bucket to bucket
  • Dry run that lists every change before anything happens
  • Journaled, resumable execution with failures reported per file
  • Saved sync jobs and gitignore-style exclusion files
  • Optional deletes, skip empty folders, skip duplicate content
  • Listing cache, parallel listing and a summary report

Object settings

  • HTTP headers, user metadata and tags
  • Storage class and server-side encryption (SSE-S3, SSE-KMS, SSE-C)
  • Canned ACLs and website redirects
  • Batch editing with a result per object
  • Versions: grouped or flat list, restore, permanent delete, download of old versions
  • Object lock: retention, legal hold, bucket default, governance bypass
  • Glacier restore with tier and days
  • Presigned GET and PUT links with a sharing wizard and optional URL shortening

Buckets and AWS services

  • Create and delete buckets
  • Bucket policy editor with validation, and public access block
  • Versioning, MFA delete, object ownership and access logging
  • Static website hosting with routing rules, and transfer acceleration
  • CORS, lifecycle, Intelligent-Tiering and replication rules, validated before sending
  • IAM users, console passwords, access keys and policies
  • CloudFront distributions per bucket and invalidations with history
  • Pinned external buckets you can access but do not own

Tools

  • Bucket usage: size and count, non-current versions, delete markers, unfinished uploads
  • Security scan for public access, missing encryption and more, with export
  • Connection diagnostics: DNS, TCP, proxy, TLS certificate, signed request and region
  • List and abort unfinished multipart uploads
  • Saved filters and listing export to CSV, Excel or Parquet
  • Mount a bucket as a read-only drive (FUSE or Dokan, optional build)

App

  • Native installers for Windows, macOS (Apple silicon and Intel) and Linux
  • System tray with transfer progress, plus taskbar and Dock progress
  • Keeps the computer awake during transfers
  • Asks before quitting with tasks running; remembers window size and position
  • Context menus, keyboard shortcuts, light and dark theme
  • English and Simplified Chinese, following the system language
  • Event log with filter, export and automatic cleanup, and local crash reports
  • No telemetry, no account, no licence key

bb command line

  • ls, cp, mv, rm, mb, rb and du
  • sync with dry run, resume and saved jobs
  • presign, edit, encrypt and decrypt
  • tag, storage-class, sse, acl, lock and restore
  • iam, cloudfront, scan, mpu and export
  • account: add, SSO sign-in, AWS profile import, folders, export and import
  • NDJSON output with --json, --dry-run and stable exit codes

Command line

The same core, in your terminal

bb prints NDJSON with --json, supports --dry-run, and has stable exit codes for scripts and CI.

  • Copy, move, sync, presign, export, scan
  • Uses the accounts of the desktop app
  • English, or Chinese with BB_LANG=zh
# sign in once, then work with buckets
$ bb account add --label work --access-key-id AKIA...
$ bb ls s3://my-bucket/photos/ --long
$ bb cp ./site s3://my-bucket/www/ --recursive
$ bb sync ./backup s3://my-bucket/backup --delete --dry-run
$ bb du s3://my-bucket --versions
$ bb presign s3://my-bucket/file.zip --expires 1h

FAQ

Questions

Is BucketBridge free?

Yes. BucketBridge is free and open source under GPL-3.0, with no account, activation, licence key or paid tier.

Does it work with S3-compatible storage?

Yes. Besides Amazon S3 it supports custom endpoints and path-style addressing, and it is tested against MinIO.

Which operating systems are supported?

Windows (MSI or portable ZIP), macOS (universal DMG for Apple silicon and Intel) and Linux (AppImage, deb and tar.gz).

Is there a command-line tool?

Yes. The bb CLI uses the same core and accounts as the desktop app, prints NDJSON with --json and supports --dry-run.

Does BucketBridge collect data?

No. There is no telemetry. The app only talks to the storage endpoints you configure, and secrets stay in the operating system keychain.
