# Package manager manifests

Manifests for installing BucketBridge (desktop app) and `bb` (CLI) through
Homebrew, Scoop and winget. The files here are generated by
`scripts/ci/package-manifests.mjs`; do not edit them by hand.

Downloads only work once the BucketBridge repository is public and the release
is published (not a draft).

## What users run

```bash
# macOS and Linux (Homebrew)
brew install --cask anupshaw50/tap/bucketbridge    # desktop app, macOS
brew install anupshaw50/tap/bb                     # CLI, macOS and Linux
```

```powershell
# Windows (Scoop)
scoop bucket add anupshaw50 https://github.com/anupshaw50/scoop-bucket
scoop install bucketbridge
scoop install bb

# Windows (winget)
winget install AnupShaw.BucketBridge
winget install AnupShaw.bb
```

## Layout

| Path | Publish to |
|---|---|
| `packaging/homebrew/Casks/`, `packaging/homebrew/Formula/` | `Casks/` and `Formula/` in the public repo `anupshaw50/homebrew-tap` |
| `packaging/scoop/*.json` | `bucket/` in the public repo `anupshaw50/scoop-bucket` |
| `packaging/winget/manifests/` | `manifests/` in a fork of `microsoft/winget-pkgs` |

## First-time setup

1. Create the public repos `anupshaw50/homebrew-tap` and
   `anupshaw50/scoop-bucket`.
2. Copy `Casks/` and `Formula/` into the tap, and the two JSON files into
   `bucket/` of the Scoop bucket. Commit and push.
3. Submit winget with `wingetcreate submit` on each version folder, or open a
   pull request against `microsoft/winget-pkgs` that adds the folders under
   `manifests/a/AnupShaw/`.

## Each release

1. Publish the GitHub release so `SHA256SUMS` is final.
2. Download it: `gh release download vX.Y.Z -p SHA256SUMS -D /tmp/sums`.
3. From the repo root run
   `node scripts/ci/package-manifests.mjs X.Y.Z /tmp/sums/SHA256SUMS`.
4. Copy the regenerated files to the tap and the bucket and push. Scoop's
   `checkver` and `autoupdate` can also bump the bucket on their own.
5. Submit the new winget version folders (`wingetcreate submit` or a pull
   request to `microsoft/winget-pkgs`). Older version folders can stay.

Notes: the MSI is a per-machine install (`Scope: machine`), so winget asks for
elevation. The CLI winget package installs `bb.exe` as a portable command.
